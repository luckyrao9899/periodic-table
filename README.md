# Periodic Table Project 🔬

An interactive **Periodic Table** built with **HTML, CSS, and JavaScript**.  
This project helps users explore chemical elements with a clean and responsive interface.

---

## 🚀 Features
- Displays all 118 chemical elements
- Hover or click to view element details like:
  - Atomic number
  - Symbol
  - Atomic mass
  - Group and period
- Responsive layout for mobile and desktop
- Lightweight and fast — runs entirely in the browser

---

## 🛠 Tech Stack
- **HTML5** for structure  
- **CSS3** for styling and layout  
- **JavaScript (ES6)** for dynamic interactivity
